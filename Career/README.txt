NIVAA Career Page

Files:
- career.html: page structure
- career.css: responsive desktop, tablet and mobile styling
- career.js: WhatsApp apply buttons and mobile navigation

Setup:
1. Keep all three files in the same folder.
2. In career.js, replace NIVAA_WHATSAPP_NUMBER with the official WhatsApp number
   in international format, digits only (India example: 919876543210).
3. In career.html, replace the # social-media href values with NIVAA's real profile URLs.
4. Check that page links match the actual filenames in your website.
5. Hero and banner photos load from Unsplash; replace their URLs with official NIVAA photos if available.

Note: This is a front-end page. Vacancy cards are currently written in HTML.
Adding/removing jobs requires editing career.html unless a backend/CMS is connected.
